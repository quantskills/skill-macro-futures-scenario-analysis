# 宏观事件—期货方法论

## 研究目标

本 Skill 研究宏观事件、预期差与期货定价之间的条件关系，观察窗口可为日内、1—5 个交易日、数周或数月。输出是情景和验证条件，不是无条件方向预测、交易指令或收益承诺。

## 标准链条

```text
事件事实与发布时间
→ actual / consensus / previous 与 surprise
→ 利率、汇率、增长、风险偏好
→ 品种供需、库存、基差、期限结构
→ 价格、成交量、持仓量的市场确认
→ 基准/偏强/偏弱情景
```

## CPI 示例

- CPI 高于预期：通常提高通胀黏性预期，可能推升实际利率和美元，对黄金估值不利；对铜和原油的作用取决于“利率压力”与“需求韧性”的相对强弱。
- CPI 低于预期：可能降低实际利率并支持黄金；铜和原油还要区分流动性改善与衰退担忧。
- CPI 符合预期：市场更可能交易此前未定价的美元、实际利率、库存和供需变化。

## 五类证据

1. **事件证据**：发布日、北京时间、报告期、实际值、预期值、前值、单位和来源。
2. **宏观证据**：美元、2Y/10Y收益率、10Y TIPS、宏观指标序列。
3. **产业证据**：产量、开工、进口、库存、仓单、现货价格和利润。
4. **期货结构证据**：主力映射、收盘/结算、成交量、持仓量、基差、近远月结构。
5. **反证**：与主链相反的数据、事件前已上涨、基差背离、库存缺失或发布滞后。

单项证据不应独立决定情景；至少列出支持证据和反证。现货、库存、持仓的变化不能自动等同于未来涨跌。

## 情景门控

每个情景必须包含：触发条件、方向倾向、时间窗口、确认条件、失效条件、替代解释和置信度。没有可靠统计样本时，不写精确概率，不写历史胜率。

## 数据时间规则

- `as_of` 是硬截止日期；
- 事件报告期不等于发布日期；
- 事件公布前不能使用 actual；
- 主力合约必须按历史日期解析；
- 连续合约换月可能造成价格跳变，不能与单一实际合约混为一谈；
- 结算价、收盘价和盘中价格必须标注来源；
- 库存和持仓数据的发布滞后必须在报告中说明。
